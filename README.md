# maximilianeberlein.github.io

Static personal website intended for GitHub Pages as the user site `https://maximilianeberlein.github.io/`. Keep the full site bundle at the repository root, including the HTML pages, styles, favicon, images, papers, logos, and project media. The original full-quality `project-media/signbot-finale.mp4` is kept locally but excluded from Git; the site uses the web-optimized copy instead.

## Publish

1. Create a public GitHub repository named exactly `maximilianeberlein.github.io` if it does not already exist.
2. Push this folder's contents to the repository's `main` branch.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/(root)`, then save.
5. The site will be available at `https://maximilianeberlein.github.io/` after deployment completes.
